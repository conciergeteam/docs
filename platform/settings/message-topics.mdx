---
title: "Message topics"
description: "Create topics so the inbox can tag and filter conversations."
---

Open **Event Settings** → **Message Topics**.

## How do I add a topic?

1. Click **New Topic**.
2. Name the topic and set team visibility if offered.
3. Click **Save**.

Row **Edit** changes visibility. **Delete** removes a topic. Associates tag conversations in [Inbox](/platform/inbox) with **Tag a topic**.
